## 👨‍💻 Sobre mí

Desarrollador de software **mobile y backend** de Colombia 🇨🇴. Construyo productos completos: desde la **API** que expone los datos hasta la **app** que llega a las tiendas.

<table>
  <tr>
    <td valign="top" width="50%">
      <h3 align="center">📱 Mobile</h3>
      <ul>
        <li>Apps multiplataforma con <b>Flutter</b> y <b>Dart</b>.</li>
        <li>Estado con <b>Riverpod</b>, <b>Bloc</b>, <b>Provider</b> y <b>GetX</b>.</li>
        <li>Persistencia local con <b>Isar</b>, <b>Hive</b> y <b>Sqflite</b>.</li>
        <li><b>Firebase</b>: Firestore, FCM y Crashlytics.</li>
        <li>Publicación en <b>App Store</b> y <b>Google Play</b> con Codemagic y Fastlane.</li>
      </ul>
    </td>
    <td valign="top" width="50%">
      <h3 align="center">⚙️ Backend</h3>
      <ul>
        <li>APIs REST con <b>Java + Spring Boot</b>, Spring Data JPA e Hibernate.</li>
        <li>Servicios en <b>Go</b> con net/http y <b>Gin</b>.</li>
        <li><b>PostgreSQL</b> y <b>MySQL</b>: modelado E-R, JOIN, GROUP BY y subconsultas.</li>
        <li>Pruebas con <b>JUnit</b>, <b>Mockito</b> y el paquete testing de Go.</li>
        <li>CI/CD con <b>GitHub Actions</b>, Docker y fundamentos de <b>AWS</b>.</li>
