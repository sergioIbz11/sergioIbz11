## 🏛️ Arquitectura & Patrones

> Estructuro mis proyectos con principios sólidos para que sean **escalables, testeables y mantenibles**:

![Clean Architecture](https://img.shields.io/badge/Clean_Architecture-0A0A0A?style=for-the-badge&logo=cleanarchitecture&logoColor=white)
![MVVM](https://img.shields.io/badge/MVVM-6750A4?style=for-the-badge&logo=android&logoColor=white)
![Design Systems](https://img.shields.io/badge/Design_Systems-00B4D8?style=for-the-badge&logo=figma&logoColor=white)

  <tr>
    <td valign="top" width="33%">
      <h3>🧅 Clean Architecture</h3>
      Separación por capas (<b>Presentation · Domain · Data</b>) con dependencias apuntando siempre hacia adentro.
    </td>
    <td valign="top" width="33%">
      <h3>🧩 MVVM</h3>

    <td valign="top" width="33%">
      <h3>🎨 Design Systems</h3>
      Componentes y tokens reutilizables (<b>colores, tipografía, espaciados</b>) para una UI consistente.

  </tr>
